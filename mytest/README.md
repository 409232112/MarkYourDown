# HTML 手动测试

在 MarkYourDown 中打开样本，建议先试 **01、04、05、09、13**，分别覆盖正常预览、结构降级、图片迁移、不可转换和编码重试。不要移动或重命名资源子目录。

| 文件前缀 | 检查点 |
| --- | --- |
| 01 | 标题、大纲、强调、引用、换行、内外链接和标准只读提示。 |
| 02 | 从 3 开始的列表、嵌套、任务状态、代码缩进与反引号。预览时点击任务框不应改值。 |
| 03 | 表格标题、正文中的竖线、无表头表格的第一行数据。 |
| 04 | 合并及嵌套表格应提示降级，内外层文本都保留。倒序列表应保留 8、4、3 的编号。 |
| 05 | 本地图、重复图、懒加载、内嵌图、缺失图。另存为后检查资源目录、重复图去重，以及重新打开 Markdown 后图片可见。 |
| 06 | 不凭字号猜标题。普通正文和详情可读，隐藏内容不显示，不能完整保留的内容有说明。 |
| 07 | 大写扩展名可打开，两个同名标题的链接应区分，普通锚点按转换说明降级。 |
| 08 | 浏览器可修复的缺失闭合标签不应导致整篇失败。 |
| 09、10、11 | 脚本空壳、纯图形、空文件应给出不可转换提示，不能另存为空 Markdown。 |
| 12 | 声明 GB18030 后自动识别，扩展汉字应正常显示。 |
| 13 | 无声明时应提示选择编码。选择 GBK 后中文应正确。 |
| 14 | UTF-8 BOM 优先于冲突的 GBK 声明，正文不应乱码。 |
| 15 | 纯图片也应得到可预览的文档。 |
| 16 | base 改变图片相对路径，srcset 选取 200w 候选，并说明使用了备用地址。 |

通用手测：

1. 打开 01，切换即时模式和源码模式，试输入、中文输入法、粘贴和删除，正文都应保持只读。查找和复制应正常。
2. 按 Ctrl+S，先取消，确认仍是只读预览。再次另存到新目录，确认标签变为 .md，可以编辑、撤销、关闭后重新打开。
3. 先打开一个 .md，再尝试把 HTML 另存为这个已打开文件，应用应拒绝并保留预览。建议使用临时 Markdown 测试。
4. 打开 05 后另存到不同目录或磁盘。验证源 HTML 未被修改，保存后的 Markdown 和资源目录可一同复制并重新打开。
5. 在外部编辑器里修改 01 的副本，切回应用检查源变更提示。重新转换应更新正文，取消时应保留此前的预览。

真实网站的整页 HTML 样本与来源见 [real-web/README.md](real-web/README.md)。
